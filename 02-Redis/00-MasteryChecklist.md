## 3. 持久化 RDB 和 AOF？

**锚点**：官方文档 Persistence

- [ ] **及格**：两种方式——**RDB**（内存快照，文件小、恢复快、有丢失窗口）、**AOF**（追加写命令，数据更安全、文件大、恢复慢）

## 4. 缓存穿透 / 击穿 / 雪崩？

**锚点**：业界公认实践（结合官方文档）

- [ ] **及格**：三种问题的**定义与危害**——穿透（查不存在的数据，打穿到 DB）、击穿（热点 key 过期瞬间大量请求打 DB）、雪崩（大量 key 同时过期 / Redis 宕机，DB 被压垮）
- [ ] **良好**：及格 + 能说出各自的**解决方案**——穿透：**布隆过滤器** + 空值缓存；击穿：**互斥锁**（setnx）+ 逻辑过期；雪崩：过期时间**加随机值** + 多级缓存 + 熔断降级
