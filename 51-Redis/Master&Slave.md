## 主从复制
主从架构->复制原理->全量vs增量->复制的问题->与MySQL复制对比->面试高频题
### 主从架构
```
// 一个主节点（Master）+ 多个从节点（Replica/Slave）
// 主节点负责写，从节点负责读（读写分离）
// 数据从主节点复制到从节点

// 配置：
// 从节点执行：replicaof 主节点IP 6379
```
为什么需要
```
// ① 读写分离：读压力分摊到从节点
// ② 高可用：主节点挂了，从节点提升
// ③ 数据备份：从节点是实时备份
// ④ 故障恢复
```
### 复制原理
旧版(2.8前)Sync
```
// SYNC：每次同步都全量
// 问题：断线重连也要全量 → 效率低
// 已废弃
```
新版（2.8+）PSync
```
// ① 主节点维护复制积压缓冲区（repl_backlog）
// ② 从节点记录已同步的偏移量（offset）
// ③ 断线重连时：
//    - 偏移量还在缓冲区 → 增量同步 ✅
//    - 偏移量已过期（缓冲区被覆盖）→ 全量同步
```
完整流程
```
① 从节点启动 → 发送 PSYNC 请求
    ↓
② 主节点判断：
   - 首次连接 → 全量同步
   - 断线重连且 offset 有效 → 增量同步
    ↓
③ 全量同步：
   - 主节点 BGSAVE 生成 RDB
   - 传输 RDB 给从节点
   - 从节点加载 RDB
   - 主节点把期间的写命令通过缓冲区发给从节点
    ↓
④ 增量同步：
   - 主节点持续把写命令发给从节点
   - 从节点执行（异步）
```
### 全量 vs 增量
全量同步
```
// 流程：
// ① 主节点 fork 子进程 BGSAVE 生成 RDB 快照
// ② 主节点把 RDB 传给从节点
// ③ 从节点加载 RDB（阻塞？从节点加载时不能服务）
// ④ 主节点把快照期间的写命令（缓冲区）发给从节点

// 开销大：RDB 生成、传输、加载
// 触发：首次、重连且 offset 丢失
```
增量同步
```
// 主节点把写命令实时推送给从节点（异步）
// 从节点执行命令

// 通过 repl_backlog（复制积压缓冲区）支持断线续传
// 默认 1MB
// 参数：repl-backlog-size

// 触发：断线重连且 offset 在缓冲区内
```
主从复制特点
```
// ① 异步复制（默认）：主节点不等从节点确认
// ② 一主多从：一个主多个从
// ③ 主从链：从节点可以有自己的从节点（树形）
// ④ 只读从节点：从节点默认只读（replica-read-only yes）
```
### 复制的问题
主从延迟
```
// 主节点写 → 从节点异步同步 → 有延迟
// 刚写完读从节点 → 可能读不到！

// 缓解：
// ① 关键读走主节点
// ② 等待机制（写后 sleep）
// ③ 从节点尽量和主节点同一机房
```
全量同步阻塞
```
// 从节点加载 RDB 时：
// ① 从节点阻塞（不能服务请求）
// ② 主节点 fork 生成 RDB 也有短暂阻塞
// ③ 传输 RDB 占用带宽

// 缓解：
// ① 尽量避免全量（repl-backlog-size 调大）
// ② 从节点用 SSD
```
脑裂
```
// 主节点网络分区（短暂失联）
// 哨兵认为主挂了 → 提升从节点为新主
// 旧主恢复 → 两个主 → 数据不一致！

// 解决：Redis 5.0+ 有 min-replicas 配置：
// min-replicas-to-write 1：主节点至少 1 个从节点才接收写
// min-replicas-max-lag 10：从节点延迟超过 10 秒不写

// 效果：旧主失联时拒绝写 → 减少脑裂数据丢失
```
数据丢失场景
```
// ① 主节点挂了，最后的写命令还没同步到从节点 → 丢
// ② 全量同步期间主节点的写可能在缓冲区溢出 → 丢

// 缓解：部署哨兵/集群 + min-replicas
```
### 和MySQL复制对比
| 对比       | MySQL 主从   | Redis 主从         |
| -------- | ---------- | ---------------- |
| **同步内容** | binlog（逻辑） | RDB（全量）+ 命令（增量）  |
| **异步**   | 默认异步       | 默认异步             |
| **断线续传** | binlog 位置  | repl_backlog 偏移量 |
| **全量**   | 快照+binlog  | RDB+缓冲区          |
| **延迟**   | 有（SQL 单线程） | 有（网络传输）          |
| **高可用**  | 需要外部工具     | 哨兵/集群            |
